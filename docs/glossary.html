Glossary

Key terms used across the accelerometer course, with definitions that study teams can adapt to their own protocol, device, and analysis plan.

Terminology QC variables Study rules

Accelerometer

A sensor that records acceleration over time, commonly along three axes.

ActiLife

ActiGraph desktop software used for device initialization, download, and selected conversion/review workflows.

Bout

A sustained interval classified within an intensity category under documented duration and bout-criterion rules. Current GGIR can calculate bouts in Parts 2 and 5.

Calibration error (calib_err)

Static calibration error after GGIR auto-calibration. Interpret it with calib_status, the QC report, the run configuration, and a pre-specified study rule rather than assuming a cutoff from the name alone.

Cleaning code (cleaningcode)

A GGIR sleep-output field used to understand cleaning decisions. Use the installed version’s output documentation and the cleaned/full file distinction; do not delete numeric codes without a complete codebook and rationale.

Clipping score (clipping_score)

Fraction of 15-minute windows in a recording affected by clipping. The official GGIR output guide states that it should be zero; any non-zero value requires contextual review.

Complete 24-hour cycle (complete_24hcycle)

A recording-level completeness score: the fraction of 15-minute positions in the 24-hour cycle for which no valid data were available on any measurement day. It is not a Boolean day-completeness flag.

Configuration (config.csv)

The resolved GGIR parameter settings stored in the output directory. Archive it with the script and software versions because later runs may reuse values from it.

Data dictionary

A record linking each analysis variable to its source file, observation level, key, unit, GGIR configuration, transformation, missing-value rule, and decision status.

ENMO

Euclidean Norm Minus One; a raw-acceleration metric that summarizes dynamic acceleration after subtracting the static effect of gravity.

Epoch

A fixed time window, such as 5 seconds, used to summarize raw acceleration into counts or other aggregate values.

.agd

ActiGraph count-based data file; the course demonstration uses a 10-second epoch .agd, which is distinct from raw .gt3x data.

.gt3x

ActiGraph raw-data file commonly used as GGIR input.

GGIR

R package used to process raw accelerometer data into quality-control, activity, and sleep-related outputs.

MET

Metabolic equivalent; a unit used to express energy expenditure relative to rest.

MVPA

Moderate-to-vigorous physical activity.

Non-wear

A period when the device is likely not being worn by the participant.

Observation level (grain)

What one row represents, such as a recording, recording-day, recording-night, or participant. It determines the key and valid merge relationship.

Pelotas/UFPel cohort example

Course example used to illustrate real operations. It is not a universal rule set.

QC

Quality control; the process of reviewing logs, summaries, plots, and protocol rules to decide whether data are trustworthy.

Raw data

High-frequency sensor measurements before epoch aggregation or derived-outcome processing.

Time window MM / WW / OO

Part 5 windows running midnight-to-midnight, waking-to-waking, and sleep-onset-to-sleep-onset, respectively.

Valid day

A day that meets the study’s minimum usable-data rule. In the course example: ≥10 hours awake wear and used as part of the ≥4 valid days plus ≥1 weekend day rule.

Visual report (visualreport)

The current per-recording GGIR Part 5 report (report...) designed to support QC. The optional legacy old_report... was not designed for data-quality assessment.

Wear protocol

The study’s instructions for when, where, and how participants wear the device.
