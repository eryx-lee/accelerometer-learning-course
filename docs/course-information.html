Scope and audience

This self-paced course supports people who need a practical introduction to accelerometer workflows, including:

  • undergraduate and graduate students in kinesiology, public health, epidemiology, data science, and related fields;
  • research assistants, coordinators, laboratory staff, and investigators;
  • faculty and instructors using the course for methods teaching or team onboarding;
  • public-health, clinical, exercise, and human-movement professionals;
  • data analysts and methodologists; and
  • company and consulting teams working in wearable technology, digital health, occupational health, research services, or related fields.

The concept route is suitable for beginners and requires only a web browser. The hands-on route also requires an approved or fictional protocol, safe practice data, and access to the relevant software or devices. The course covers device placement and programming, file organization, GGIR quality review and processing, and preparation of a participant-level dataset.

The course is educational guidance, not a substitute for a study protocol, statistical analysis plan, local data-governance requirements, or device-manufacturer instructions.

  • Technical baseline: GGIR 3.3-7 documentation
  • Video-version note: the Module 4 demonstration was recorded using GGIR 3.3-6; the lesson text identifies decisions that should be checked against the version installed for a new study
  • Published video quality: all ten course videos are delivered from 1920 × 1080 masters; technical corrections and the removal of production-only material are retained in the published versions

Software interfaces and defaults can change. Before production analysis, consult the current GGIR parameter documentation and record the package version and complete configuration used for the study.

AI-assisted video transparency

The course videos use AI-assisted production and narration. English captions and readable transcripts were generated from the media and corrected against the course terminology. They are provided for review and accessibility, but they may not reproduce every spoken hesitation or visual-only detail. Please report a caption or content error with the module name and timestamp.

Accessibility

The site is designed to support keyboard navigation, visible focus, responsive text and controls, descriptive headings, captioned videos, readable transcripts, and reduced-motion preferences. We aim to improve toward WCAG 2.2 Level AA; this statement is not a certification of full conformance.

Known limitations:

  • Some instructional details appear visually inside recorded software demonstrations and may not all be described in the audio.
  • Downloaded R and Stata files require compatible software or a plain-text editor.
  • Third-party documentation linked from the course has its own accessibility practices.

For an accessibility problem, open an issue and describe the page, device, browser, and assistive technology if you are comfortable doing so.

Privacy

No account is required. The required entry questionnaire, course progress, quiz results, optional module feedback, required final feedback, and certificate record are stored only in your browser’s local or session storage. The public course site does not transmit those responses to the course team. Clearing site data or using another browser or device will reset them. Feedback is shared externally only if the learner deliberately opens and submits the optional prefilled GitHub Issue.

Because this is a static GitHub Pages course, the required entry questionnaire is a client-side course-flow gate rather than an authentication or security control. Do not enter confidential or sensitive information.

Links to GitHub and external documentation are governed by those services’ own privacy practices.

Certificate of completion

Learners who complete the entry questionnaire, mark all eight modules complete, pass the final knowledge check, and save the required final feedback can create a personalized certificate of completion.

The certificate uses Illinois-inspired color and formal typography and can be printed or saved as a PDF from the completion page.
