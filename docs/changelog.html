Change Log

Track notable content, technical, accessibility, media, and resource changes to the published course.

Version 1.3.0 August 11, 2026 Living course

Post-1.3 course-entry migration — September 2, 2026

  • Removed GitHub sign-in and the learning-data consent widget from learner-facing course pages.
  • Moved the required course-entry questions to the LA PASSSTA Lab form hosted by University of Illinois Forms.
  • Kept module progress, quiz selections, course-page feedback, and the local non-verifiable certificate in the learner’s browser rather than creating new synchronized course records.
  • Retained the standalone legacy administration and certificate-verification services for records collected under the earlier opt-in system.

Version 1.3.0 — August 11, 2026

  • Added opt-in learner authentication and a protected, centralized course record for the entry questionnaire, module activity and completion, submitted quiz attempts, feedback, and certificate status.
  • Added server-authoritative quiz scoring, completion checks, high-entropy certificate issuance, and public verification by certificate code.
  • Added a role-protected administrator dashboard with course-funnel, learner, item-analysis, Module 8, certificate, freshness, and export views.
  • Added versioned consent, learner export and deletion controls, row-level access policies, audit events, idempotent writes, and a documented 24-month inactivity retention period.
  • Kept the course overview and public information available without an identifiable record, required sign-in and consent for the recorded learning pathway after backend activation, and retained browser storage only as a resilience fallback.

Pre-1.3 maintenance update — August 11, 2026

  • Replaced the entry questionnaire’s age field with a learner-entered name during the browser-local phase; Version 1.3 subsequently moved opted-in questionnaire and certificate records to the protected course service.
  • Preserved compatibility with existing browser records that contain the former age field and ensured that a valid name-based record takes priority during old-site progress migration.
  • Separated saved course feedback from public GitHub Issues so the issue action never copies the saved response, and documented GitHub Pages’ security logging separately from the course learning record.
  • Replaced third-party MathJax and polyfill requests with native MathML and added an automated check that rejects non-course JavaScript sources.

Version 1.2.0 — August 3, 2026

  • Replaced the three-phase learning-journey section with explicit guidance for students, researchers, faculty, health professionals, analysts, and company or consulting teams.
  • Moved the course creators near the top of the homepage, added Otávio Leão’s title and a LA PASSSTA Lab introduction, and updated Eric Li’s name and role.
  • Added a required browser-local entry questionnaire before learners can open a module directly.
  • Converted mini-activities and knowledge checks to A–D multiple-choice interactions with answer feedback and saved results.
  • Added optional feedback to every module and required final feedback to the completion pathway.
  • Added a personalized completion certificate with Illinois-inspired formal styling and print-to-PDF support.
  • Added a labelled sample certificate preview beside the homepage completion requirements.
  • Replaced the homepage lab mark with a true transparent-background asset and removed its surrounding tile.
  • Moved captions out of the video picture by default and added below-video, on-video, and off display choices.
  • Kept long Knowledge Check questions inside their cards across desktop and mobile layouts.
  • Moved the repository and public course URL into the LA PASSSTA Lab GitHub organization.

Version 1.1.0 — July 25, 2026

  • Restored all ten course videos to 1920 × 1080 delivery while preserving captions, transcript timing, technical corrections, and the removal of production-only material.
  • Introduced a more refined visual system with stronger hierarchy, richer depth, upgraded navigation, video, module, resource, FAQ, and course-progress surfaces, and responsive refinements.
  • Replaced the editorial serif display type with a screen-first Manrope system, with clearer weights, spacing, and line height across page titles, cards, navigation, metrics, and learning components.
  • Reorganized the homepage around a clearer three-phase learning journey and more concise course-value, pathway, resource, and completion guidance.

Version 1.0.0 — July 25, 2026

  • Clarified the intended audience, prerequisites, module inputs and outputs, and course-completion pathway.
  • Added corrected technical guidance for GGIR quality reports, completeness, valid days, bouts, sleep, thresholds, and version recording.
  • Added English captions and expandable readable transcripts for every course video.
  • Removed production-only narration from the placement video and corrected the Module 4 threshold label.
  • Added a downloadable toolkit with study logs, synthetic practice data, R and Stata examples, and a capstone.
  • Added persistent browser-local progress, resume support, previous/next navigation, skip navigation, visible focus, and mobile refinements.
  • Added course, FAQ, accessibility, privacy, AI-video, rights, citation, and maintenance information.
  • Added social-sharing metadata, a custom preview image, automated checks, and performance-oriented media formats.
